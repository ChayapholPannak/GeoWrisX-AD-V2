5) บัตตรรายกระบวนคานัย (Approval กล่องยา — เดิมแต่จะตระเตำระเฟสใหม่)

sequenceDiagram
  participant P as ผู้ป่วย (กดปุ่มบนกล่องยา)
  participant PB as กล่องยา ESP32
  participant GW as device-event gateway
  participant DB as Neon
  participant CU as Caregiver (Dashboard)
  PB ->> PB: ตรวจ BLE phone proximity (60 วิ)
  PB ->> GW: PILLBOX_REQUEST {compartment, ble_proof}
  GW ->> DB: INSERT pillbox_approvals (pending, expires 60s)
  CU ->> GW: POST /api/approve-pillbox
  GW ->> DB: approve_pillbox_request()  ยืนยันทีละขั้น
  DB -->> GW: status=queued (30 วิ)
  GW -->> PB: UNLOCK_COMPARTMENT
  PB ->> GW: ยืนยัน unlock + MED_EVENT {W1-W2}
  GW ->> DB: INSERT med_intakes ('taken')
